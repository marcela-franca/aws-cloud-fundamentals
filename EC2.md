# EC2 (Computação Elástica na Nuvem)

O **EC2** é um serviço da AWS que possibilita acesso a **capacidade computacional escalável** na nuvem.  
Ele garante **virtualização de alto desempenho**, permitindo que múltiplos usuários acessem e gerenciem ambientes virtualizados com configurações personalizadas para cada demanda.  

Em essência, o EC2 é um **servidor em nuvem** que pode ser facilmente ajustado:  
- Se for necessário mais processamento, a instância pode ser ampliada.  
- Se for preciso menos, a carga pode ser reduzida, otimizando custos.  

## Tipos de instâncias

- General Purpose (ex: t2, t3)
- Compute Optimized (ex: c5, c6)
- Memory Optimized (ex: r5, r6)
- Storage Optimized (ex: i3, d2)
- Accelerated Computing (ex: p3, g4)

## Modelos de compra

- On-Demand (pago por hora/segundo)
- Reserved Instances (até 72% mais baratas)
- Spot Instances (super econômicas, mas podem ser interrompidas)
- Savings Plans

Os diferentes tipos e modelos de compra agregam muito valor ao EC2, como no caso das **Instâncias Spot**.  
Essas instâncias aproveitam capacidade de computação não utilizada e são oferecidas a um custo muito menor.  
Quando bem estruturadas, podem gerar **economia significativa** e ainda atender às necessidades das cargas de trabalho.  

Os **Savings Plans** também são uma ótima opção de economia, pois, com compromissos de longo prazo, é possível reduzir consideravelmente os custos de processamento das instâncias.  
Ou seja, tudo pode ser adaptado ao seu modelo de negócio e ao que funciona melhor para o seu **ecossistema computacional**.  

# EC2 (Elastic Compute Cloud)

**EC2** is an AWS service that provides access to **scalable computing capacity** in the cloud.  
It ensures **high-performance virtualization**, allowing multiple users to access and manage virtualized environments with configurations tailored to their specific demands.  

In essence, EC2 is a **cloud server** that can be easily adjusted:  
- If more processing power is needed, the instance can be scaled up.  
- If less processing power is required, the load can be reduced, optimizing costs.  

## Instance Types

- General Purpose (e.g., t2, t3)  
- Compute Optimized (e.g., c5, c6)  
- Memory Optimized (e.g., r5, r6)  
- Storage Optimized (e.g., i3, d2)  
- Accelerated Computing (e.g., p3, g4)  

## Pricing Models

- **On-Demand** (pay per hour/second)  
- **Reserved Instances** (up to 72% cheaper)  
- **Spot Instances** (very cost-effective but can be interrupted)  
- **Savings Plans**  

Features such as different instance types and pricing models add great value to EC2, like the use case of **Spot Instances**.  
These instances take advantage of unused computing capacity and are offered at a much lower cost.  
When well-structured, they can generate **significant savings** while still meeting workload demands.  

**Savings Plans** are also a great cost-saving feature, where by committing to long-term “packages” you can reduce processing costs for your instances.  
In other words, everything can be adapted to your **business model** and what works best for your **computational ecosystem**.
