# S3 (Serviço de Armazenamento de Blocos Elástico)

O **S3**, assim como o EBS, é uma forma de armazenamento de dados. Porém, diferente da solução acoplada,
o S3 apresenta mais **autonomia nas atividades relacionadas ao armazenamento**, pois **armazena objetos** e não apenas dados de leitura e escrita.

Os arquivos podem ser, por exemplo, imagens, logs, backups, etc. Podemos armazenar dados fazendo upload e download para qualquer tipo de processamento,
não se limitando apenas a instâncias. Esses dados podem ser utilizados em outros tipos de aplicações.

# S3 (Simple Storage Service)

**S3**, like EBS, is a form of data storage. However, unlike attached storage solutions, S3 **provides greater autonomy** for storage-related operations, ]
as it **stores objects** rather than just read/write data.

Files can include, for example, images, logs, backups, etc. Data can be stored by performing uploads and downloads for any type of processing, 
not limited to instances. These objects can also be used in other types of applications
