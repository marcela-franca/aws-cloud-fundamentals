# S3 (Serviço de Armazenamento de Blocos Elástico)

O **S3**, assim como o EBS, é uma forma de armazenamento de dados. Porém, diferente da solução acoplada,
o S3 apresenta mais **autonomia nas atividades relacionadas ao armazenamento**, pois **armazena objetos** e não apenas dados de leitura e escrita.

Os arquivos podem ser, por exemplo, imagens, logs, backups, etc. Podemos armazenar dados fazendo upload e download para qualquer tipo de processamento,
não se limitando apenas a instâncias. Esses dados podem ser utilizados em outros tipos de aplicações.

Existem alguns modelos de S3, com aplicação voltada a diferentes períodos de armazenamento.

## Tipos de armazenamento S3:

- S3 Standard: Alta disponibilidade e performance, indicado para dados acessados com frequência.
- S3 Intelligent-Tiering: Move automaticamente os dados entre classes de acordo com o padrão de acesso, otimizando custo.
- S3 Standard-IA (Infrequent Access): Para dados acessados com menos frequência, mas que ainda precisam de rápido acesso.
- S3 One Zone-IA: Similar ao Standard-IA, mas armazenado em apenas uma zona de disponibilidade, mais barato.
- S3 Glacier: Para arquivamento de dados com acesso eventual, mais econômico.
- S3 Glacier Deep Archive: Arquivamento de longo prazo, custo mínimo, acesso muito raro.

# S3 (Simple Storage Service)

**S3**, like EBS, is a form of data storage. However, unlike attached storage solutions, S3 **provides greater autonomy** for storage-related operations, ]
as it **stores objects** rather than just read/write data.

Files can include, for example, images, logs, backups, etc. Data can be stored by performing uploads and downloads for any type of processing, 
not limited to instances. These objects can also be used in other types of applications.

There are several S3 storage classes, designed for different storage durations and access patterns.

## S3 Storage Classes

- S3 Standard: High availability and performance, suitable for frequently accessed data.
- S3 Intelligent-Tiering: Automatically moves data between classes based on access patterns to optimize costs.
- S3 Standard-IA (Infrequent Access): For data accessed less frequently but still requiring fast retrieval.
- S3 One Zone-IA: Similar to Standard-IA, but stored in a single availability zone, more cost-effective.
- S3 Glacier: For data archiving with occasional access, more economical.
- S3 Glacier Deep Archive: Long-term archival with minimal cost and very rare access.
