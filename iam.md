# IAM (Gerenciamento de Identidade e Acesso)

O IAM é um serviço fundamental para entendermos a **hierarquia de acessos** e como ela garante a **segurança da infraestrutura na nuvem**.  

Com o IAM, podemos criar **limitações de acesso**, o que é um dos pilares da **Segurança da Informação**. Integrar o IAM ao sistema é primordial, pois, em caso de tentativas de fraude, ataques de hackers ou ações mal-intencionadas de um colaborador, existem barreiras que protegem os recursos construídos e os custos que poderiam ser gerados.  

Por exemplo, sem controle de acesso adequado, um invasor poderia utilizar inúmeros serviços, gerando um faturamento imprevisível e prejuízos significativos ao dono da infraestrutura.  

Dessa forma, o IAM é **essencial para a estruturação de uma organização**, garantindo que cada usuário tenha **apenas os privilégios necessários** para executar suas funções, respeitando o princípio do menor privilégio.

# IAM (Identity and Access Management)

IAM is a fundamental service for understanding **access hierarchy** and how it ensures **security in cloud infrastructure**.  

With IAM, we can create **access restrictions**, which is one of the pillars of **Information Security**. Integrating IAM into the system is essential, because in cases of fraud attempts, hacker attacks, or malicious actions by an insider, there are barriers that protect the resources built and the costs that could be incurred.  

For example, without proper access control, an attacker could use multiple services, generating unpredictable billing and significant losses for the infrastructure owner.  

Thus, IAM is **essential for organizational structuring**, ensuring that each user has **only the necessary privileges** to perform their tasks, following the principle of least privilege.
