# Fundamentos da AWS Cloud

Este projeto tem como objetivo compartilhar o conhecimento aplicado sobre as **tecnologias fundamentais da AWS**, as principais ferramentas que sustentam a infraestrutura em nuvem e como sua aplicabilidade faz parte do ciclo de vida da nuvem.  

## Serviços e Tecnologias Abordadas

Os seguintes serviços da AWS serão apresentados e estudados com maior profundidade:  

- **IAM** (Identity and Access Management – Gerenciamento de Identidade e Acesso)  
- **EC2** (Elastic Compute Cloud – Computação Elástica na Nuvem)  
- **EBS** (Elastic Block Store – Armazenamento de Blocos Elástico)  
- **S3** (Simple Storage Service – Serviço de Armazenamento Simples)  
- **AMI** (Amazon Machine Images – Imagens de Máquina da Amazon)  
- **Snapshots**  
- **Funções Lambda**  

## Conceitos Principais

Além disso, também exploraremos alguns conceitos-chave que estruturam essas tecnologias:  

- **Regiões e Zonas de Disponibilidade**  
- **Níveis de Permissões**  
- **Modelos de Computação em Nuvem**

# AWS Cloud Fundamentals

- **IAM** (Identity and Access Management)  
- **EC2** (Elastic Compute Cloud)  
- **EBS** (Elastic Block Store)  
- **S3** (Simple Storage Service)  
- **AMI** (Amazon Machine Images)  
- **Snapshots**  
- **Lambda Functions**  

## Core Concepts

In addition, we will also explore some key concepts that structure these technologies:  

- **Regions and Availability Zones**  
- **Permission Levels**
